# 🧶 knit. — 생성형 AI 기반 개인 맞춤형 뜨개 창작·공유 플랫폼

> **말로 설명하면, 도안이 됩니다.**

## 1. 프로젝트 소개

**knit.**은 뜨개질을 즐기는 사용자들이 작품을 계획하고, 제작 과정을 기록하며, 다른 사람들과 정보를 공유할 수 있도록 만든 웹 애플리케이션입니다.

기존의 뜨개 활동은 원하는 도안을 직접 검색해야 하고, 작품별 제작 과정과 정보를 따로 기록해야 한다는 불편함이 있습니다.

이러한 문제를 해결하기 위해 생성형 AI를 활용한 뜨개 도안 제작 기능과 작품 기록 및 공유 기능을 하나의 플랫폼에 통합했습니다.

또한 포인트와 레벨에 따라 성장하는 고양이 캐릭터를 도입하여 사용자가 지속적으로 뜨개 활동에 참여할 수 있도록 구성했습니다.

## 2. 개발 동기 및 목적

뜨개질은 자신만의 작품을 직접 만들 수 있다는 장점이 있지만, 원하는 디자인의 도안을 찾기 어렵거나 제작 과정에서 필요한 정보를 체계적으로 관리하기 어렵다는 한계가 있습니다.

이에 AI 기술을 활용하면 사용자가 원하는 작품을 설명하는 것만으로 도안 초안을 만들 수 있을 것이라고 생각했습니다.

단순히 AI 도안 생성 기능만 제공하는 것이 아니라, 작품 제작 과정의 기록과 사용자 간 소통까지 지원하는 통합 플랫폼을 개발하는 것을 목표로 했습니다.

**주요 개발 목표**
- 생성형 AI를 활용한 개인 맞춤형 뜨개 도안 제작
- 작품별 제작 정보와 진행 과정의 체계적인 기록
- 사용자 간 작품 공유 및 정보 교류
- 포인트와 캐릭터 성장 시스템을 통한 지속적인 참여 유도

## 3. 주요 기능

### ① AI 도안 생성

Google Gemini API를 활용하여 사용자가 원하는 뜨개 작품의 도안 초안을 생성하는 기능입니다.

- 작품 종류, 숙련도, 뜨개 방식 등 다양한 조건 선택
- 원하는 크기, 실 종류, 바늘, 게이지 등 세부 정보 입력
- 사용자의 요구 사항을 바탕으로 AI 도안 생성
- 생성된 도안 확인 및 수정 요청
- 완성된 도안의 텍스트 저장 및 다운로드

사용자가 직접 도안을 검색하는 데 드는 시간을 줄이고, 개인의 취향과 제작 조건에 맞는 도안을 얻을 수 있도록 설계했습니다.

### ② 뜨개 기록장

사용자가 제작 중이거나 완성한 작품의 정보를 기록하고 관리하는 기능입니다.

- 작품별 제작 정보 기록
- 사용한 실과 바늘 등 재료 정보 관리
- 게이지 및 제작 과정 기록
- 작품별 진행 상황과 결과 정리

이를 통해 여러 작품의 제작 정보를 한곳에서 관리할 수 있도록 했습니다.

### ③ 뜨개모임

뜨개질에 관심 있는 사용자들이 서로 소통하고 정보를 공유할 수 있는 커뮤니티 기능입니다.

- 지역별 뜨개 모임 정보 확인
- 새로운 모임 및 게시글 작성
- 작품 공유와 뜨개 관련 질문
- 다른 사용자와 의견 및 정보 교류

지역과 게시글 종류를 구분하여 원하는 정보를 쉽게 찾을 수 있도록 구성했습니다.

### ④ 캐릭터 성장 및 포인트 시스템

사용자의 활동을 포인트로 연결하고, 포인트에 따라 고양이 캐릭터가 성장하는 기능입니다.

- 뜨개 기록장, AI 도안, 뜨개모임 등의 활동을 통한 포인트 획득
- 포인트에 따른 사용자 레벨 변화
- 레벨에 따른 캐릭터 장식과 아이템 변화
- 포인트 및 사용자 랭킹 확인
- 다음 레벨까지 필요한 포인트와 성장 진행도 표시

캐릭터의 편물 길이와 장식, 뜨개바늘 색상이 포인트에 따라 달라지도록 구현하여 사용자가 자신의 활동에 따른 변화를 시각적으로 확인할 수 있도록 했습니다.

## 4. 사용 기술 및 개발 환경

- **Python**: 프로그램의 전체 기능 구현
- **Streamlit**: 웹 화면 구성 및 사용자 인터페이스 제작
- **Google Gemini API**: 사용자 조건에 맞는 뜨개 도안 생성
- **google-genai**: Gemini API 연결 및 요청 처리
- **SQLAlchemy**: 사용자 정보와 활동 데이터 관리
- **SQLite / PostgreSQL**: 포인트 및 관련 데이터 저장
- **HTML, CSS, SVG**: 고양이 캐릭터와 애니메이션 구현
- **GitHub**: 소스 코드 관리
- **Streamlit Community Cloud**: 웹 애플리케이션 배포

## 5. 프로젝트 실행 방법

### 1) 저장소 복제

```bash
git clone 저장소주소
cd knit
```

### 2) 필요한 라이브러리 설치

```bash
pip install -r requirements.txt
```

### 3) API 키 설정

Google Gemini API를 사용하기 위해 API 키를 설정해야 합니다.

`.streamlit/secrets.toml` 파일을 생성하고 다음과 같이 작성합니다.

```toml
GEMINI_API_KEY = "발급받은_API_키"
GEMINI_MODEL = "사용할_모델명"
```

실제 API 키는 외부에 공개되지 않도록 관리합니다.

### 4) 프로그램 실행

```bash
streamlit run main.py
```

명령어를 실행하면 웹 브라우저에서 knit.의 메인 화면을 확인할 수 있습니다.

## 7. 개발 과정에서 고려한 점

### ① AI 도안 생성의 정확성과 활용성

사용자가 입력하는 조건이 다양하기 때문에 작품 종류, 숙련도, 재료 등의 정보를 구분하여 AI에 전달하도록 구성했습니다. 또한 생성된 결과를 확인하고 수정 요청을 할 수 있도록 하여 사용자의 요구를 반영할 수 있게 했습니다.

### ② 캐릭터 구현의 한계와 해결

초기에는 캐릭터를 이미지 파일로 구현하는 방법을 고려했지만, 포인트에 따라 편물의 길이와 장식이 달라지는 모습을 표현하는 데 한계가 있었습니다.

이를 개선하기 위해 SVG와 CSS를 활용하여 캐릭터를 코드로 직접 구현했습니다. 포인트에 따라 캐릭터의 외형이 변화하도록 만들고, 꼬리와 눈, 뜨개바늘에 애니메이션을 적용하여 생동감을 더했습니다.

### ③ 사용자 데이터와 포인트 관리

사용자의 포인트와 활동 정보를 지속적으로 관리하기 위해 데이터베이스를 활용했습니다. 또한 공통 기능을 common.py에 분리하여 여러 페이지에서 동일한 사용자 정보와 포인트 관리 기능을 사용할 수 있도록 구성했습니다.
